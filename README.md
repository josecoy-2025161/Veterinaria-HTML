# Veterinaria Huellitas Felices

Sitio web informativo desarrollado únicamente con **HTML5 y CSS3**, como proyecto colaborativo para trabajo en equipo y control de versiones con **Git y GitHub**.

---

## Descripción del proyecto

La página web representa a la **Veterinaria Huellitas Felices**, un negocio dedicado al cuidado, salud y bienestar de las mascotas.  
El sitio cuenta con un **menú de navegación principal** y **cinco vistas**, cada una asignada a un integrante del equipo.

---

## Tecnologías utilizadas

- HTML5  
- CSS3  
- Git  
- GitHub  
- Visual Studio Code

## 👥 Trabajo colaborativo

Cada integrante del equipo es responsable de una vista:

- **Servicios:** Información sobre atención veterinaria  
- **Veterinarios:** Equipo médico  
- **Citas:** Horarios y agenda  
- **Tienda:** Productos para mascotas  
- **Contacto:** Información de comunicación  

Todos los integrantes utilizan el mismo archivo CSS y el mismo menú de navegación.

---

## Control de versiones

El proyecto utiliza Git para el control de versiones y GitHub como repositorio remoto.

Comandos básicos utilizados:

- git init
- git add .
- git commit -m "Primer commit del proyecto"
- git push
